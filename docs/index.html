Two levels of feedback

Short by default, so stepping through 40 moves never turns into homework.

1

Quick take

One line on what the move did, one on what happens next, and a better move when there was one.

2

Deep dive

What your move changed, your opponent's plan move by move, and how to answer it. Opens with a click or Alt+D.

3

Grounded in the engine

Each sentence comes from Stockfish's best line plus a board check for forks, hanging pieces and threats.

Install

Pick one. Both share the same code and look the same on chess.com.

Userscript (any browser)

  1. Install Tampermonkey or Violentmonkey.
  2. Click the button below, then Install.
  3. Open a finished game or Analysis on chess.com.
Install the userscript

Extension (Chrome, Edge, Brave)

  1. Download chess-move-coach-extension.zip from the latest release and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the unzipped folder.
Download the latest release
⏸

Fair play built in. Using an engine during a game against a person breaks chess.com's rules. The coach stays paused while that kind of game is running, and in puzzles. It works in Analysis, in games against the computer, and on any game once it has ended.

Privacy

The extension sends nothing anywhere; the engine runs in your browser. The userscript does the same, unless the local engine can't start and you switch on the optional online engine, which sends only the board position (a FEN string) to chess-api.com.
